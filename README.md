# WorkHub – Enterprise Work Management & IT Service Desk

> 🚧 **Status:** Active Development (In Progress)

A centralized full-stack platform to streamline client IT requests, manage task workflows, and provide real-time analytics for enterprise teams.

## 🛠️ Tech Stack
*   **Frontend:** React, TypeScript, Tailwind CSS, Vite
*   **Backend:** Python, FastAPI, SQLAlchemy
*   **Database:** MySQL
*   **Security:** JWT Authentication, Role-Based Access Control (RBAC), Argon2 Hashing

## ✨ Key Features
*   Multi-role dashboards (Super Admin, Admin, Employee, Client).
*   Secure JWT Authentication and dynamic password updating.
*   Real-time Super Admin "Cockpit" with live SQL data aggregation and Recharts visualizations.
*   Responsive UI with Dark Mode integration and state-driven animations.
*   Ticket tracking and task assignment workflows.
